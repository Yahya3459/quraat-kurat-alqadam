# قرعة كرت القدم

صفحة عربية تفاعلية لسحب أسماء اللاعبين وتوزيعهم بالتتابع على أربعة فرق.

## التشغيل محليًا

```bash
python3 -m http.server 4173
```

ثم افتح: <http://localhost:4173>

## ملاحظات

- الصفحة تعتمد على Tailwind CSS وCanvas Confetti من CDN.
- تم وضع شعار مؤقت في `alc_logo.svg` إلى حين استبداله بشعار المركز الأصلي.
- يتم نشر الصفحة تلقائيًا عبر GitHub Pages عند كل تحديث على فرع `main`.
