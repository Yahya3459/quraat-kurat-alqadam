# مركز القرعات

موقع عربي تفاعلي لقرعات مركز الأمجاد للغات، ويحتوي على صفحة استقبال لاختيار نوع القرعة.

## الصفحات

- `index.html`: صفحة الاستقبال والاختيار بين القرعتين.
- `league.html`: القرعة السابقة لتوزيع أسماء الطلاب على أربعة فرق، محفوظة كما هي في صفحة مستقلة.
- `classic.html`: قرعة جديدة عشوائية بين ثلاثة من أصحاب التوقعات الصحيحة لنتيجة الكلاسيكو، مع صورهم وإعلان احتفالي كامل الشاشة للفائز بالجائزة.

## التشغيل محليًا

```bash
python3 -m http.server 4173
```

ثم افتح: <http://localhost:4173>

## النشر

يتم نشر الصفحة تلقائيًا عبر GitHub Pages عند تحديث فرع `main`.
